## ANSWER TO THE QUESTION

**"How is the intermediary page being hosted?"**

**Answer:** It's hosted by an embedded Java HTTP server (`HttpServer`) running inside the Android app itself, listening on `localhost:8888`. The HTML is embedded as a String in the `getCastReceiverHtml()` method of `CastProxyServer.java`. When Chromecast connects, the server returns this HTML. The HTML then loads video from the `/cast` endpoint, which proxies the video while automatically injecting authentication headers.

**No external hosting. No files on disk. Completely self-contained in the APK.**
